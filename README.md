## PointMarker - 画像上のポイント・ルートをマーキング （旧PickPoints）

読み込んだルート図(png)に、ポイント・ポイント間のルート・スポット・エリアをマーキング(png内座標)して保存。

PNG画像のハイキングマップから視覚的にポイント・ルート・スポット・エリアを選択し、座標データをJSONファイルまたはFirebase Firestoreに保存するWebアプリケーション。

画像とJSONファイルの読み込みには、File System Access API対応ブラウザ（Chrome 86+、Edge 86+）が必要。

**【共有プロジェクト対応】**
- Firebase Firestoreを使用した**共同編集機能**を搭載
- 認証済みユーザーなら誰でも全プロジェクトを読み書き可能
- PNG画像ファイル名がプロジェクトキー（画像はメンバーにのみ配布。Firestoreへのアクセス自体は制限しない）

### 入力
- ハイキングマップ（ポイントとポイント間のルートあり）から切り出したPNG画像
- 本アプリで出力したJSON、またはFirebase Firestoreに保存したデータ（編集を再開する場合）

### 出力
- 各ポイントの画像上の位置情報（JSON・Firestore）
- ポイント間の各ルートに対する画像上の位置情報（JSON・Firestore）
- 各スポットの名称と画像上の位置情報（JSON・Firestore）
- 各エリアの名称と頂点の画像上の位置情報（JSON・Firestore）
